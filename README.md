# Aspect IT

Сайт IT-аутсорсинговой компании: обновление сайтов для бизнеса.

## Страницы

- `index.html` — главная (герой, услуги, преимущества, кейсы, форма)
- `services.html` — услуги с ценами и процессом работы

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 8080
```

Сайт будет доступен по адресу http://localhost:8080
